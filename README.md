# Ekzo Manga CMS - Frontend Mockup

This is the initial frontend mockup for the Ekzo Manga CMS landing page.

## How to View
Simply open `index.html` in your web browser.

## Features Included
- **RTL Support**: Arabic layout direction.
- **Dark Mode**: Default dark theme.
- **Tailwind CSS**: Utility-first styling (via CDN).
- **Responsive Design**: Mobile-friendly navigation and grid.
- **Mock Data**: Placeholder images and text for manga entries.
